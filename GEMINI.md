# Midnight Boogie Festival
Sitio web oficial del festival de música.

## Stack
- Frontend: Astro (raíz del repo)
- CMS: Sanity en midnight-boogie-cms/ — el cliente edita contenido ahí
- Tailwind CSS para estilos
- Deployment: Vercel

## Reglas
- Color corporativo: naranja #EC9726
- No modificar esquemas de Sanity ni romper layouts existentes
- Diseño pixel-perfect
- Responder en español
